折腾了几天，这个博客终于重新上线了。

## 为什么又搭了一个博客

以前也搭过博客，用的是常见的博客框架，绑定在 GitHub 上，还配过自己的域名。后来域名过期了，博客也被改坏过一次，慢慢就不怎么用了。

这次重新搭，原则很简单：

- 不用花太多心思在维护上；
- 写起来方便，不用调格式；
- 风格干净一点，程序员一点。

## 这个博客是怎么搭的

技术上用了 [Astro](https://astro.build/) 这个静态博客框架，主题基于 [AstroPaper](https://github.com/satnaing/astro-paper)，托管在 GitHub Pages 上。

发布流程非常简单：**写一篇 Markdown 文章，推送到 GitHub，剩下的事情全自动完成**。

## 以后会写什么

主要会记录这些内容：

- 日常开发中遇到的问题和踩坑记录；
- 学习新技术时的笔记和总结；
- 偶尔一些生活随笔。

希望这次能坚持写下去。欢迎常来看看。
